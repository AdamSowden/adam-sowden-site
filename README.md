# Adam Sowden — Personal Site

Next.js 15 site for adamsowden.com. Zero person business strategy for service business owners and solo operators.

## Tech Stack

- Next.js 15 (App Router) + TypeScript + Tailwind CSS
- Sanity CMS (content store)
- Anthropic API (AI chat widget)
- Google Gemini (image generation)
- GHL (email campaigns via API + behavioural workflows)

## Setup

1. Copy `.env.local` placeholder values and add real keys
2. Add Sanity project ID after Sanity setup
3. Add API keys before building features that require them

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Important

Methodology docs in `ai-marketing-agency/clients/adam-sowden/` must be completed before any content work begins. All placeholder files need real content before the blog pipeline, email pipeline, or AI chat widget can be built.
